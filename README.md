# SomeBankingApp

A simple banking application developed as part of the "Strumenti di sviluppo software" course (DIBRIS, Università di Genova). The project is organized into two main components: a **FastAPI** backend and an **Angular** frontend.

## Project Structure

- **`backend/`**: Contains the FastAPI REST API, SQLAlchemy models, and the local SQLite database (`bank.db`).
- **`frontend/`**: Contains the Angular user interface.

---

## Requirements

- **Python** 3.10 or later
- **Node.js** and **npm** (for the frontend)
- **Docker** (for containerized execution)
